# Derivative-Calculator (Python)
This Python project computes the derivative of user-defined polynomials using the Power Rule:

**d[ax^n] = (n)ax^(n-1)**

I created this project to practice translating mathematical concepts into computer programs. This project demonstrates concepts such as:

## Concepts Demonstrated

- Functions
- Variable-Length Arguments (`*args`)
- Index-Based Iteration and Looping
- Conditional Statements
- String Manipulation
- Mathematical Computation
- Data Representation
- Algorithm Design
- Problem Decomposition

## Future Improvements

## How to Use

Represent your polynomial as a list of numbers where each coefficient is immediately followed by its exponent.

**Example:**

```
5x^7 - 9x^6 + 10x^8
```

becomes

```
[5, 7, -9, 6, 10, 8]
```

Constants are represented with an exponent of zero.

**Example:**

```
8
```

becomes

```
[8, 0]
```
